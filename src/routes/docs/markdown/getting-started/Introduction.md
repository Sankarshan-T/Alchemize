# Welcome to Alchemize

Alchemize is a program where you build projects, submit them for review, and earn rewards.

---

## How It Works

1. Choose a project idea.
2. Build your project and document your work.
3. Submit it for review.
4. Check the shop for available rewards.

---

## Seasons

Program details can change between seasons. Check official announcements for the
latest project guidance and reward information.

---

## Rewards

Everything you earn can be spent in the shop.

### Shop Rewards

Check the current shop for available rewards and pricing.

### Seasonal Bonuses

Some rewards are reserved for participants who go above and beyond.

These may include:

* Top participants
* Exceptional projects
* Community contributors
* Successful referrals

The reward lineup may change every season.
